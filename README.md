# Social Media Engagement Analysis

Internship task for Internee.pk analyzing engagement trends (likes, comments, 
shares, reach) across Instagram, LinkedIn, and Facebook.

## Key Finding
Carousel posts had the highest engagement rate (7.95%) across all platforms — 
more than 5x higher than Text posts (1.48%).

## Tools
Python, Pandas, Plotly, Jupyter Notebook

## Note
Due to API access restrictions, this uses a representative simulated 
dataset 500 posts to demonstrate the full analysis workflow.
